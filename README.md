# P8105 Homework 5 — zb2367

Open `p8105_hw5_zb2367.Rproj` in RStudio, then open
`p8105_hw5_zb2367.Rmd` and click **Knit**. The report uses `tidyverse`,
`broom`, `knitr`, and `rmarkdown`; packages must already be installed.

[Read the rendered report](p8105_hw5_zb2367.md).

The 20 original participant CSV files are stored in `data/` and were
extracted without modification from the
[official data archive](https://p8105.com/data/hw5_data.zip).
All input paths are relative to this project. Simulations use fixed seeds.
